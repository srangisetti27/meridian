G10
Audit log  observability.py → logs/queries.jsonl Every question: route, trust level, validation verdict, latency. Never-raises design; persists via Docker volume. Live stats in the sidebar.
 
Deployment  Dockerfile · docker-compose.yml Test-gated build — the 42-test suite runs inside docker build; an image with failing data validation cannot be produced. Healthcheck every 30s. One command: docker compose up.
 
Verification harnesses 42 automated tests · router accuracy eval (22/24 golden set) · adversarial audit posture — F4 was found by attacking our own outputs; its detection is now automated.

The design in one sentence

The model chooses from a menu and phrases results — it never cooks. Worst case is a visible misroute; the invisible wrong number, the failure that burned this client, has no code path.

Production path

CSVs → read-only Salesforce/Snowflake with snapshot journaling (makes F4-style re-dating impossible to hide) · engine behind an API · validations become pipeline gates · SSO + row-level access · audit log → monitoring stack · intents grow one audited analysis at a time.
